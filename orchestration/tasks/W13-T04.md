# W13-T04 — main-py-glue

## Objective

Wire the runtime bridge into `main.py` without breaking the live Gemini path.
Prefer adapter/glue over rewriting JarvisLive.

## Owned paths

- `main.py`
- `tests/unit/integration/test_main_glue.py` (or `tests/unit/main/`)

## Forbidden paths

- `ui.py` (W13-T05), `server/**`, wholesale rewrite of Gemini Live loop
- Committing keys; writing key values into repo

## Acceptance

- When Gemini is selected / default: existing live audio path still runs.
- Bridge stack is constructed at startup (best-effort); failures log, do not crash.
- Optional: tool calls can consult SafetyPolicy when bridge.safety is present
  (deny high-risk without approval path → log + safe message; do not hard-break
  legacy tools that lack registry entries — treat unknown as legacy-allow or
  document degrade).
- One commit; app remains importable without optional stacks.

## Depends on

W13-T03 (runtime-bridge) integrated.
