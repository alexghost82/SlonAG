# W13-T03 — runtime-bridge

## Objective

Create a headless runtime bridge that assembles the new stack (providers/router,
memory, safety, network, STT/TTS factories) with graceful degrade when pieces
are missing. Used by later `main.py` / `ui.py` glue. Do **not** edit `main.py`
or `ui.py` in this task.

## Owned paths

- `mark/bridge/**` (new package)
- `tests/unit/bridge/**`

## Forbidden paths

- `main.py`, `ui.py`, `server/**`, `speech/tts/download.py`, `ios/**`
- Rewriting provider/memory/safety implementations
- Reading or writing live API key values into bridge modules

## Design

```text
RuntimeStack = build_runtime_stack(
  repo_root=...,
  key_provider=callable,  # injected; never hardcode secrets
  provider_id="gemini",   # default preserves live Gemini path intent
  network_mode=...,
)
```

Each subsystem is optional: missing deps → `None` + status message string.
No network downloads. No UI imports.

## Acceptance

- Unit tests cover: all-missing degrade; mock router/memory present; never
  raises on missing optional pieces.
- `key_provider` is the only secret surface; bridge does not open
  `api_keys.json` itself (caller may inject a reader).
- One commit.

## Stop conditions

- Need to change shared contracts → change request.
