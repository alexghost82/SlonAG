# W06-T03 — memory-sqlite

## Objective

A SQLite memory store with propose-then-commit writes, secret rejection, CRUD/clear/disable, local embeddings hook, and a JSON→SQLite migrator that does not lose allowed data.

## Context

Legacy `memory/memory_manager.py` still writes `long_term.json` and calls `or_client`. **Do not edit those files.** Put the new stack under `mark/memory/**`. Do not read or copy the user's real `memory/long_term.json`. Tests use fixtures + `tmp_path`.

- `mark/memory/**`

## Forbidden paths

- `memory/**` (legacy package: `memory_manager.py`, `config_manager.py`, `memory/__init__.py`)

- `requirements*.txt`, `i18n/**`, `memory/*.json`

## Required interfaces

stdlib `sqlite3` only. Inject embedder. Inject db path.

## Implementation requirements

- Modules conceptually: `database.py`, `repository.py`, `embeddings.py`, `policy.py`, `migrations/` (all under `mark/memory/`)
- Record types: `preferences` | `projects` | `confirmed_facts` | `summaries` | `action_history`
- Each record: id, type, key, value, source, created_at (and updated_at)
- `propose(record) -> Proposal` does not write; `commit(proposal_id)` writes; the model path must not call SQLite directly
- Policy rejects passwords, API keys, tokens, payment-card-like values (and configurable extra categories)
- `list` / `get` / `update` / `delete` / `clear_all` / `set_enabled(False)` (writes no-op when disabled)
- Embeddings via injected local embedder; `privacy_profile="fully_local"` or `network_mode="offline"` must not call a cloud embedder
- `migrate_json(old: dict | Path) -> stats` maps legacy categories (`identity`, `preferences`, `projects`, `relationships`, `wishes`, `notes`) into the new types without dropping allowed values; skip secret-like values
- DB path is injected; never write `memory/long_term.json`; never commit a `.db` file
- No `or_client`. No network. No API keys in the database.

## Tests

- propose does not persist; commit does
- secrets rejected
- CRUD, clear, disable
- offline/fully_local does not call cloud embedder
- JSON fixture migrates all allowed categories; secret entries skipped
- no `memory/*.json` writes

```bash
python -m pytest tests/unit/memory -q
```

## Acceptance criteria

SQLite store exists; secrets stay out; migrator keeps allowed data; legacy `memory/` untouched; one commit.

## Stop conditions

- need to edit legacy `memory/` or `or_client.py`
- need to add a pip package
- need to read a real user `long_term.json`
