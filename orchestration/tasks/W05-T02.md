# W05-T02 — stt

## Objective

A local STT adapter implementing `SpeechToTextProvider` with Russian default, cancel, interim text, VAD hook, and echo-guard so assistant TTS is not transcribed.

## Context

Do not add `faster-whisper` / whisper.cpp to requirements. Wrap optional binaries/libraries behind an injected engine. Tests must not need a microphone or model file.

## Base commit

Content parent: `b2d5b3d57099e7bbae0b81171dd916f3c5c3258b`.

- `speech/stt/**`
- `tests/unit/speech/stt/**`

## Forbidden paths

- `speech/__init__.py`, `speech/tts/**`, `mark/runtime/**`, `providers/**`, `ui.py`, `requirements*.txt`, `i18n/**`
- `tests/unit/speech/__init__.py` (do not create; it can shadow imports)

## Required interfaces

`SpeechToTextProvider`, `AudioRequest`, `Transcript` from `providers.contracts`. Register factory id `"stt_local"` via `providers.registry.register` without editing `registry.py`.

## Implementation requirements

- `LocalSTTProvider(engine=..., language="ru", is_assistant_speaking: Callable[[], bool] | None = None)`
- `transcribe` returns `Transcript`; if `is_assistant_speaking()` is true, return empty transcript (echo guard)
- Support cancel: a `cancelled` flag/event aborts and returns empty or partial
- Interim callback optional: `on_partial(text: str)`
- VAD hook optional: `vad_detect(audio: bytes) -> bool`; if false, skip engine
- Default language `ru`
- Engine protocol: `transcribe(audio, language) -> str` — mock in tests
- Do not hit the network. Do not read API keys.

## Tests

- Russian default language
- echo guard skips engine
- cancel prevents engine call / returns empty
- VAD false skips engine
- interim callback invoked when engine supplies partials (if you support it)
- factory registered as `stt_local`

python -m pytest tests/unit/speech/stt -q
