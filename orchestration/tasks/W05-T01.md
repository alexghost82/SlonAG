# W05-T01 — local-runtime-manager

## Objective

A headless local-runtime manager that can start/stop Ollama, llama.cpp server, or a generic OpenAI-compatible loopback process (via injected runners), list catalog entries, and refuse model pulls without size+license confirmation.

## Context

Chat adapters already exist in `providers/local`. This task manages the **process and catalog**, not HTTP chat. Do not edit `providers/local/**`. Do not download models. Do not edit `ui.py`.

Hardware profiles are recommendation **data**, not a pinned model id.

## Base commit

Worktree HEAD from the Wave 5 spec commit. Content parent: `b2d5b3d57099e7bbae0b81171dd916f3c5c3258b`.

## Owned paths

- `mark/runtime/**`
- `tests/unit/runtime/**`

## Forbidden paths

- `speech/**`, `providers/**`, `ui.py`, `main.py`, `requirements*.txt`, `i18n/**`, `config/**`, `mark/app/**`

## Required interfaces

Read-only: `providers.local.endpoint.is_loopback_url`, default local URLs. Inject subprocess/transport in tests.

## Implementation requirements

- `RuntimeKind`: `ollama` | `llama_cpp` | `openai_compatible`
- `RuntimeManager.start/stop/status` using an injected runner (do not spawn real daemons in tests)
- Default endpoints must be loopback; reject remote URLs unless `allow_remote=True`
- Catalog entry fields: id, size_bytes, context, capabilities, ram_gb, vram_gb, source, license, status
- `request_pull(model, *, confirm_size: bool, confirm_license: bool)` raises unless both confirms are true; the pull itself is an injected hook (no network)
- Hardware profile table as data: 8–16 / 16–32 / 32–64 / 64+ GB → size-class recommendations, not a hardcoded model name
- OOM / start failure returns a structured error code (`oom`, `not_running`, …) plus a Russian message function in this package (do not edit i18n catalogs)
- Metrics slots: `ttft_ms`, `tokens_per_sec` (set by caller/injected sampler; can be None)
- No cloud fallback if runtime is down

## Tests

- start/stop/status with fake runner
- remote URL rejected
- pull without confirms raises
- pull with confirms calls hook once
- profile recommendations contain no fixed model id
- OOM path does not raise uncaught

```bash
python -m pytest tests/unit/runtime -q
```

## Acceptance criteria

Manager exists; no real downloads; no `ui.py`; tests pass; one commit.

## Stop conditions

- need to edit `providers/local` or requirements
- need to download a model
