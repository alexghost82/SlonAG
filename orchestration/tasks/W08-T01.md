# W08-T01 — network-policy

## Objective

A single headless `NetworkPolicy` that all future network clients consult before HTTP/DNS. Modes: `offline`, `tools_only`, `hybrid`. Offline blocks external egress; loopback stays available for local runtime; tools_only limits egress to an allowlisted tool set; activity is journaled without secrets.

## Context

Wave 7 SafetyPolicy owns SSRF checks for **tool** URLs (`mark.safety.check_url` blocks private/loopback). NetworkPolicy is broader: it decides whether a **client** may leave the host at all. Do not edit `providers/router.py`, adapters, or `ui.py` in this task — provide the policy API and an offline scenario test that proves cloud would be blocked.

## Implementation requirements

- `NetworkMode`: `OFFLINE = "offline"`, `TOOLS_ONLY = "tools_only"`, `HYBRID = "hybrid"` (align with `config.schema.NETWORK_MODES`)
- `NetworkPolicy(mode=..., *, tool_allowlist: frozenset[str] | None = None, allow_private_lan: bool = False)`
- `check_request(*, url: str, tool: str | None = None, purpose: str = "") -> NetworkDecision`
  - `OFFLINE`: deny any non-loopback http(s) host. Allow loopback (`127.0.0.1`, `localhost`, `::1`) for local runtime. Do not perform DNS or open sockets.
  - `TOOLS_ONLY`: external hosts only if `tool` is in the injected allowlist; otherwise deny. Loopback still allowed.
  - `HYBRID`: allow public http(s); still block metadata / link-local / unambiguous SSRF literals unless explicitly for a documented local-runtime purpose. Prefer reusing the same host classification ideas as safety URLs without importing and weakening tool SSRF.
- `allows_cloud_provider(provider_id: str) -> bool`: false in `OFFLINE`; also false when `privacy_profile` equivalent is fully-local if you accept an optional `privacy_profile=` on the policy. Cloud ids: `gemini`, `openai`, `openrouter`.
- Proxy guard: if env inject `HTTP_PROXY`/`HTTPS_PROXY`/`ALL_PROXY` would send a loopback target through an external proxy, refuse the request (or strip/ignore proxy for loopback). Inject `environ` for tests — do not mutate `os.environ` globally.
- Journal: append entries `{tool, domain, time, reason, allowed}` with secret redaction. `activity()` / `recent()` returns a snapshot for a future UI. Never log URLs with query tokens or `Authorization` material.
- Typed errors: `NetworkDeniedError` with a stable `code` (`offline`, `tool_not_allowed`, `unsafe_host`, `proxy_forced_external`, …) and a message that never includes secrets.
- No real network. No API keys. Do not call providers.

## Tests

Unit (`tests/unit/network`):

- offline denies `https://example.com`, allows `http://127.0.0.1:11434`
- tools_only denies external unless tool is allowlisted
- hybrid allows public https, denies metadata `169.254.169.254`
- `allows_cloud_provider` false in offline
- proxy env cannot turn loopback into external egress
- journal has tool/domain/reason, no secret substrings

Offline scenario (`tests/offline/test_network_offline.py`):

- Simulate “local runtime failed, would fall back to cloud”: with `NetworkPolicy(mode=offline)`, asserting cloud provider ids are denied even after a local failure flag. No live HTTP.

```bash
python -m pytest tests/unit/network tests/offline/test_network_offline.py -q
```
