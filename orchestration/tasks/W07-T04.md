# W07-T04 — desktop-typed-ops

## Objective

Replace the `exec` sandbox in `actions/desktop.py` with a closed set of typed operations. The model must not receive `Path`, `exec`, `eval`, `getattr`, `subprocess`, `os`, or a full `pyautogui` object.

## Context

Starts **after W07-T01**. Keep `desktop_control(parameters=..., player=None)` as the executor entry.

## Base commit

`d2e309adf389c71989d57633ea1d85c7e904acd0` — integration/main after W07-T01.

## Owned paths

- `actions/desktop.py`
- `tests/unit/actions/test_desktop.py`

## Forbidden paths

- `agent/**`, `actions/file_controller.py`, `actions/reminder.py`, `or_client.py`, `ui.py`
- `mark/safety/**` (read-only import ok)

## Implementation requirements

- Remove `_execute_generated_code` / `exec` / `compile(..., "exec")` / `_ask_gemini_for_desktop_action`
- Typed ops only: `mouse.click`, `keyboard.type`, `keyboard.shortcut`, `window.activate`, `screen.capture`, `file.copy`
- Dispatch on `parameters["op"]` (or equivalent). Unknown op → typed error, no exec
- Backends injected (fake mouse/keyboard/screen/copy in tests). Do not import `or_client`
- `file.copy` must not delete; destination checks can be conservative
- `authorize` before mutating ops
- Do not expose `pyautogui` to model-supplied code

## Tests

- no `exec`/`eval` in the module (or only in comments — prefer zero)
- unknown op does not execute
- each typed op calls the matching fake backend
- Gemini/or_client is not imported on the happy path

```bash
python -m pytest tests/unit/actions/test_desktop.py -q
```

## Stop conditions

- keeping an exec sandbox “for compatibility”
- need to edit executor
