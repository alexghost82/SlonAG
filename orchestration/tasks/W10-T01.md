## Objective

## Implementation requirements

- Semantic color tokens (SwiftUI `Color` / Asset-free: adaptive light/dark via system semantic colors where possible)
- Type scale helpers compatible with Dynamic Type
- Spacing and corner radius constants
- Components: primary/secondary button, section header, status badge (online/offline), empty state placeholder
- `MarkRemoteApp` entry: minimal `App` + root `TabView` or `NavigationStack` shell that compiles; tabs can be placeholders labeled in English/Russian comment — prefer Russian user-visible strings
- No network calls. No Keychain. No AI keys.
- Swift 6 concurrency-safe (no force-unwrap of secrets)
