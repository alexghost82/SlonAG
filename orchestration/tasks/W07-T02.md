# W07-T02 — executor-no-codegen

## Objective

Stop automatic generated-code execution. Unknown tools return a typed error. The model cannot install packages or run arbitrary Python through the executor.

## Context

Starts **after W07-T01 is integrated**. Import `mark.safety` read-only. Do not edit safety, file_controller, desktop, or reminder.

## Base commit

`d2e309adf389c71989d57633ea1d85c7e904acd0` — integration/main after W07-T01.

## Owned paths

- `agent/executor.py`
- `tests/unit/agent/**`

## Forbidden paths

- `mark/safety/**`, `actions/**`, `ui.py`, `main.py`, `or_client.py`, `config/api_keys.json`
- `agent/planner.py`, `agent/error_handler.py` unless a one-line import is unavoidable — prefer not to touch them

## Implementation requirements

- Delete or permanently disable `_run_generated_code` as an execution path. Do not spawn `sys.executable` on model-written files. Do not call `pip`.
- Tool `generated_code`: return/raise a typed safety error (or a diff-only stub that **does not run**). No Gemini/or_client call required.
- Unknown tool: `UnknownToolError` from `mark.safety`. **Never** fall back to generated code.
- Before `_call_tool` runs an action, call `authorize` + `validate_args`. If decision is deny, do not call the action. Confirm/biometric: require an injected confirmer; default confirmer in tests can approve/deny.
- Do not read `config/api_keys.json` on the generated-code or unknown-tool paths. Prefer not to read it at all in new code; existing translate helpers may stay but tests must not need a live key (guard/lazy).
- Keep public `AgentExecutor.execute` and `_call_tool` names so callers still import.

## Tests

- unknown tool does not execute and raises `UnknownToolError`
- `generated_code` does not run Python / does not call Gemini
- authorize deny prevents the action
- no `api_keys.json` required for these paths

```bash
python -m pytest tests/unit/agent -q
```

## Stop conditions

- need to edit `mark/safety` or other actions
- need a live API key
