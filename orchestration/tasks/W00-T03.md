## Implementation requirements

Write `docs/audit/user-changes.md` with a table for every modified or untracked user file discovered in the two source working copies.

Columns:

- path
- location (openclaw / cursor-workspace)
- type (modified tracked / untracked)
- classification (`later-port` / `never-port` / `already-isolated`)
- target wave or task if later-port
- notes

Rules:

- Never copy secret values, key material, or memory contents into the document.
- Refer to secrets only as "present, redacted".
- Classify `actions/game_updater.py` winreg-guard as later-port for `W01-T04`.
- Classify `requirements-macos.txt` as later-port for `W01-T02`.
- Classify keys, memory, `.venv`, `__pycache__`, `.app` bundles, `.DS_Store`, and the nested duplicate clone as never-port.
- Re-run `git status --short` in both source trees and record the date of the scan.
