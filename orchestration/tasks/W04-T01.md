# W04-T01 — router

## Objective

A provider router that sends one chat/stream request to one selected adapter, checks capabilities first, and never applies a hidden model fallback. Fallback is a pluggable policy defaulting to "never".

## Context

Wave 3 adapters register factories: `gemini`, `openai`, `openrouter`, `local`, `ollama`, `llama_cpp`. `config.schema` has `privacy_profile`, `provider_id`, `network_mode`, `model_roles`. Do not edit those modules.

Offline / `fully_local` must not call cloud providers even if the local adapter fails.

## Required interfaces

`get` / `register` from `providers.registry`. `require_capability`. Adapter packages may be imported to register factories. Constructor-injected API keys / provider instances only — do not read `api_keys.json`.

## Implementation requirements

`Router` (or `ProviderRouter`) must:

- Accept `provider_id`, optional `network_mode` / `privacy_profile`, a `key_provider` callable ` (provider_id) -> str | None `, and optional prebuilt provider instances for tests.
- `chat(request)` / `stream(request)` call `require_capability` then the selected provider. One model id per attempt.
- Define `FallbackPolicy` protocol with `next(failed_provider_id, error) -> str | None`. Default implementation always returns `None` (never).
- If a policy returns another provider id, the router may retry **once** on that id only if `privacy_profile` / `network_mode` allow it. Cloud is forbidden when `network_mode == "offline"` or `privacy_profile == "fully_local"`.
- Local → cloud fallback is never implicit. Default policy never does it.
- Unified `ChatEvent` stream regardless of adapter.
- Missing key → `ProviderAuthError` / validate-not-ok, no network.
- Do not implement cost accounting (W04-T02).
- Do not implement UI (W04-T03).
- Do not copy `or_client.py` fallback lists.

## Tests

`tests/unit/providers/test_router.py` (unique name):

- routes to a mock/injected provider
- capability failure does not call the provider
- default policy never falls back
- offline / fully_local refuses `gemini` / `openai` / `openrouter`
- local failure in offline does not call a cloud mock
- stream yields `ChatEvent`

Use injected fakes; do not hit the network.

```bash
python -m pytest tests/unit/providers/test_router.py -q
```
