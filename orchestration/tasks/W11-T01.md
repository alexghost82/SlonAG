1. **Security gates** (`tests/security/`): smoke tests covering injection isolation, path traversal deny, SSRF deny, no `shell=True` / no codegen / unknown-tool typed error, and Desktop API responses without secret material. Reuse production APIs (`mark.safety`, `agent.executor`, `actions.*`, `server.app`). Fake sentinel keys only (same style as unit tests).
2. **Integration gates** (`tests/integration/`): in-process Desktop Control API smoke (loopback default, unauth 401, no live network) plus NetworkPolicy×SafetyPolicy combined offline/cloud denial.
3. **Offline gates** (`tests/offline/test_beta_offline_gates.py`): SafetyPolicy + NetworkPolicy offline smoke (no sockets, no DNS).
4. **Beta checklist** (`docs/audit/beta-gates.md`): pass / fail / deferred for unit, integration, security, offline, iOS (`swift test`), ruff, mypy, secret scan, license audit. Explicitly: CC BY-NC recorded; not commercially ready; Piper deferred; no public bind / push / APNs.
5. No new pip packages. No live HTTP. Do not enable public bind.
