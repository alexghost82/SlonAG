# W04-T03 — setup-wizard-ui

## Objective

A first-run setup wizard module in Russian (via `tr`) that collects privacy profile, provider, key-or-local-runtime, model roles, and a summary of what stays local vs what goes to the cloud. Do not rewrite all of `ui.py`.

## Context

Starts after W04-T01 is integrated. Use `tr` from `localization`. Use `config` settings schema. Do not store live keys in settings files; call `set_secret` / accept a secret setter callback.

## Base commit

`e0d972c526193f1b1d381e15cc001c9050cf1148` — integration/main after W04-T01.

## Owned paths

- `mark/app/**`
- `tests/unit/app/**`

## Forbidden paths

- `ui.py`, `main.py` (wire later; do not edit now)
- `providers/router.py`, adapter trees
- `policies/**`, `config/**` (read-only)
- `i18n/**`, `localization/**` (read-only `tr`; if a key is missing, use an existing key or stop with a change request — do not edit catalogs)

## Required interfaces

`tr`, `validate_settings` / `Settings` (read-only), `set_secret` as an injected callable in tests.

## Implementation requirements

Wizard steps (data + validation, PyQt optional):

1. Privacy profile
2. Provider
3. API key **or** local runtime discovery (loopback URL only)
4. Model list (injected catalog, no live network in tests)
5. Role assignment; reject unsupported role/model pairs via `require_capability` / `supports`
6. Optional test request hook (injected)
7. Summary: what is local, what is sent to the cloud

Prefer a headless `SetupWizardState` / controller so tests do not need a display. A PyQt widget is optional and must not be imported at test collection if it needs a display.

Default language remains Russian through `tr`.
Do not write `api_keys.json` directly.
Do not assign a model a role it does not support.

## Tests

- step order and validation
- unsupported role rejected
- non-loopback local URL rejected
- summary distinguishes local vs cloud
- secrets go through the injected setter, not settings JSON

```bash
python -m pytest tests/unit/app -q
```

## Acceptance criteria

Wizard module exists; `ui.py` unchanged; tests pass without a display; one commit.

## Stop conditions

- need to edit `ui.py` or i18n catalogs
- need a live provider call
