# W05-T03 — tts

## Objective

A local TTS adapter implementing `TextToSpeechProvider` with Russian text normalization, sentence chunking, interrupt/barge-in, voice/speed/volume, and preview. **Do not implement Piper.**

## Context

Piper is blocked until the user approves a specific implementation and voice license. Use an injectable synthesizer (and optionally macOS `say` only if invoked through that injection — tests must not call `say`).

## Base commit

Content parent: `b2d5b3d57099e7bbae0b81171dd916f3c5c3258b`.

- `speech/tts/**`

## Forbidden paths

- `speech/__init__.py`, `speech/stt/**`, `mark/runtime/**`, `providers/router.py`, `ui.py`, `requirements*.txt`, `i18n/**`
- `tests/unit/speech/__init__.py` (do not create; it can shadow imports)
- any Piper download, binary, or voice file

## Required interfaces

`TextToSpeechProvider`, `SpeechRequest`, `AudioStream`. Register `"tts_local"`. Read-only: `localization.ru_locale.normalize_yo` if useful.

## Implementation requirements

- `LocalTTSProvider(engine=..., voice=..., speed=1.0, volume=1.0)`
- `synthesize` returns `AudioStream`; engine is injected
- Split text into sentences and call engine per sentence (streaming-by-sentence)
- `interrupt()` stops further sentences (barge-in)
- `preview(text)` uses the same path
- Russian normalization: numbers/abbreviations can be a small local normalizer; `ё` via `normalize_yo` if imported
- Expose `is_speaking` for STT echo-guard
- No Piper. No network. No API keys.

## Tests

- sentence chunking
- interrupt stops remaining sentences
- `is_speaking` true during synthesize, false after
- preview calls engine
- factory `tts_local`
- no Piper imports

python -m pytest tests/unit/speech/tts -q
