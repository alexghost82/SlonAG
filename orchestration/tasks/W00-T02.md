# W00-T02 — license-inventory

## Objective

Produce a third-party license registry that documents current constraints and does not claim commercial readiness.

## Context

`readme.md` states Creative Commons BY-NC 4.0 for personal/non-commercial use only. There is no root `LICENSE` file. `requirements.txt` mixes cross-platform and Windows-only packages and includes both `google-genai` and deprecated `google-generativeai`.

Commercial distribution is a user decision and is out of scope for this task.

## Base commit

`d5cf4765d983378df626fb8ed4461ad8f95d38ec` — orchestration bootstrap on `integration/main`.

## Owned paths

- `THIRD_PARTY_LICENSES.md`
- `docs/licenses/**`

## Forbidden paths

- all other paths
- do not create a root `LICENSE` that grants commercial rights
- do not edit `readme.md`, `requirements.txt`, or application code

## Required interfaces

None.

## Implementation requirements

Create `THIRD_PARTY_LICENSES.md` and `docs/licenses/INVENTORY.md`.

Must record:

- Source project license: CC BY-NC 4.0 as stated in `readme.md`.
- Commercial use is not permitted without a separate grant or an independent rewrite of protected code.
- This modernization must not claim the product is commercially ready.
- Current Python dependencies from `requirements.txt`, with license and notes where known.
- Mark unverified licenses as `UNKNOWN — verify`.
- Note that `google-generativeai` is deprecated; `google-genai` is the supported replacement, but this task does not change requirements files.
- Windows-only packages: `pygetwindow`, `comtypes`, `pycaw`, `win10toast`, `pywinauto`.
- Open items for later waves: Piper TTS implementation license, model licenses, voice licenses, datasets.

Do not invent SPDX identifiers when unsure.
Do not download models or voices.
Do not contact external legal services.

## Tests

No unit test runner yet. Self-check:

- every package from `requirements.txt` appears in the inventory
- the documents contain no commercial-ready claim
- no secret material is included

## Acceptance criteria

- Inventory files exist under owned paths only.
- CC BY-NC constraint is explicit.
- No statement that the project is commercially ready.
- Gaps are marked `UNKNOWN — verify`.
- One logical commit.

## Deliverables

- `THIRD_PARTY_LICENSES.md`
- `docs/licenses/INVENTORY.md` and any supporting notes under `docs/licenses/`
- one commit
- report with SHA, file list, and open legal questions

## Stop conditions

- pressure to decide commercial vs rewrite vs personal-only
- need to edit `readme.md` or add a commercial `LICENSE`
- discovered secret
