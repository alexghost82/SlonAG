# W01-T02 — requirements-split

## Objective

Split runtime dependencies by platform, remove the deprecated Gemini SDK from install files, and keep a compatibility shim in `requirements.txt`.

## Context

Current `requirements.txt` mixes Windows-only packages, duplicates `pillow`/`Pillow`, and lists both `google-genai` and deprecated `google-generativeai`. `ui.py` needs PyQt6, but the tracked requirements file omits it. OpenClaw has an untracked `requirements-macos.txt` (read-only reference; do not copy secrets).

`requirements-dev.txt` and `pyproject.toml` belong to W01-T03. Do not create or edit them.

## Required interfaces

Read-only: current `requirements.txt`, `setup.py`, OpenClaw `/Users/slon/.openclaw/workspace/Slon/requirements-macos.txt` (package names only).

## Implementation requirements

Create platform files:

- `requirements-base.txt` — cross-platform runtime deps. Include `google-genai` and `PyQt6`. Exclude `google-generativeai`. Deduplicate Pillow. Use compatible version ranges, not floating unpinned names where a conservative range is known. Do not invent yanked versions.
- `requirements-windows.txt` — `-r requirements-base.txt` plus `pygetwindow`, `comtypes`, `pycaw`, `win10toast`, `pywinauto` (and only other Windows-only runtime deps that were in the original file).
- `requirements-macos.txt` — `-r requirements-base.txt` plus any macOS-only extras that are actually required. Use the OpenClaw file as a hint, not a blind copy. Do not re-add `google-generativeai`.
- `requirements-linux.txt` — `-r requirements-base.txt` plus Linux-only extras if needed (none unless justified).
- `requirements.txt` — compatibility shim that includes `-r requirements-base.txt` and a short comment pointing to the OS files. It must not pull Windows-only packages onto macOS/Linux.

Update `setup.py`:

- detect OS and install the matching requirements file
- keep Playwright browser install
- use the product name Slon in user-facing setup text

- do not install `requirements-dev.txt`

Do not add lockfiles.
Do not add `keyring` unless W01-T01 has already requested it in a change request (it should not; T01 is stdlib-only).
Do not edit license inventory files.

## Tests

Under `tests/unit/requirements/`:

- parse the requirement files (text-level, no need to pip install the world)
- `google-generativeai` is absent from all owned requirements files
- `google-genai` is present in base
- `PyQt6` is present in base or every OS file
- Windows-only packages are not in base, macos, or linux files
- `pillow`/`Pillow` is not duplicated inside a single file
- `requirements.txt` is a shim and does not list `pywinauto` / `pycaw` / `win10toast` / `comtypes` / `pygetwindow`
- `setup.py` maps darwin → macos file, win → windows file, linux → linux file (test the selection function; extract logic if needed so it is importable, or parse `setup.py` source)

Do not edit `tests/conftest.py`.

Run:

```bash
python -m pytest tests/unit/requirements -q
```
