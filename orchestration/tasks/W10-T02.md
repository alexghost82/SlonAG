# W10-T02 — networking

## Objective

iOS networking + security + DTO models that speak the Desktop Control `/v1` API: loopback-first base URL, pairing credential in Keychain, authenticated URLSession client, and a WebSocket events client interface. No AI provider keys on device.

## Context

## Implementation requirements

- Models: Codable DTOs for status, pairing start/complete, chat, tasks, approvals, models, memory, screen, API error envelope; `idempotencyKey` on mutating requests
- Security: Keychain wrapper for `device_id` + `device_secret` / refresh material; never log secrets; LocalAuthentication gate helper for high-risk approvals (protocol + mockable)
- Networking:
  - `DesktopAPIClient` with injectable `URLSession` / baseURL
  - Default base URL `http://127.0.0.1:…` (configurable port); reject constructing client with public bind host unless explicit `allowNonLoopback` (default false)
  - Attach Bearer access token from a token provider protocol
  - Methods mirroring major `/v1` routes (can return decoded DTOs or throw `APIError`)
  - `EventsClient` protocol for `/v1/events` (URLSessionWebSocketTask behind protocol; tests use a fake)
- No Bonjour implementation required in T02 (Pairing feature owns discovery UX); client may accept a discovered host only if loopback/LAN policy allows — default stay loopback
- No third-party SPM packages
