# W13-T05 — ui-py-glue

## Objective

Connect the new stack more comprehensively into `ui.py` / JarvisUI (beyond LOCAL
TTS + DESKTOP API): status for providers/network/memory/safety/STT, TLS-aware
Desktop API start, graceful degrade.

## Owned paths

- `ui.py`
- `tests/unit/ui/test_ui_runtime_glue.py` (headless-friendly hooks only; mock Qt
  if needed — prefer testing bridge methods JarvisUI exposes without full GUI)

## Forbidden paths

- `main.py`, `server/tls.py` implementation (consume API only), download without
  consent UX that hits network in tests

## Acceptance

- On init: log bridge status lines when bridge available.
- Desktop API toggle can enable TLS when certs exist / generate opt-in path
  documented in UI log (no silent public bind).
- LOCAL TTS remains; optional note pointing to `python -m speech.tts download
  --consent`.
- Missing pieces do not crash UI.
- One commit.

## Depends on

W13-T02 (TLS API), W13-T03 (bridge) integrated.
