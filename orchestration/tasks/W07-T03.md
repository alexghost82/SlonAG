# W07-T03 — file-controller-safe

## Objective

Harden `actions/file_controller.py`: real confirmation, allowlisted dirs, canonical paths, trash-only delete, no permanent-delete fallback.

## Context

Starts **after W07-T01**. Import `mark.safety` read-only. Keep `file_controller(parameters=..., player=None)` as the executor entry.

## Forbidden paths

- `agent/**`, `actions/desktop.py`, `actions/reminder.py`, `mark/safety/**` (read-only import ok)
- `ui.py`, other `actions/*`

## Implementation requirements

- Inject allowlist roots and a confirmer (tests use `tmp_path`)
- Resolve with `Path.resolve()`; reject if the canonical path escapes the allowlist
- Reject filesystem root, entire home, and system dirs (`/`, `/etc`, `/System`, `C:\`, `C:\Windows`, …) even if somehow listed
- Delete goes to trash (`send2trash` if present, else injected trash hook). **No** `unlink`/`rmtree` permanent fallback
- Write/delete/move/rename require confirmation when `authorize` says confirm/exact_confirm. Missing confirm → no mutation
- Log full canonical path via injected logger (no secrets)
- Undo for move/rename when the previous path is still available (best-effort)
- List/read stay risk 0 if inside allowlist

## Tests

- traversal / escape from allowlist blocked
- home/root/system blocked
- delete without confirm does not remove
- delete with confirm uses trash hook, not permanent delete
- public `file_controller(...)` still works with injected hooks
