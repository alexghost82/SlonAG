# W00-T01 — repo-safety

## Objective

Git ignores secrets, user memory, models, virtualenvs, logs, caches, and local app bundles.

## Context

The upstream repository has no `.gitignore`. A working copy at `/Users/slon/.openclaw/workspace/Slon` contains live API keys in untracked `config/api_keys.json` and user memory in `memory/long_term.json`. Those files must never be added to this clone.

Minimum ignore list from the implementation plan §7.1, plus extra local-runtime paths.

## Base commit

`d5cf4765d983378df626fb8ed4461ad8f95d38ec` — orchestration bootstrap on `integration/main`.

## Owned paths

- `.gitignore`
- `.gitattributes`

## Forbidden paths

- all other paths
- especially `main.py`, `ui.py`, `or_client.py`, `requirements.txt`, `config/**`, `docs/**`, `THIRD_PARTY_LICENSES.md`, `orchestration/**`

## Required interfaces

None. This task does not depend on application APIs.

## Implementation requirements

Create `.gitignore` with at least:

```gitignore
.venv/
__pycache__/
*.py[cod]
.DS_Store
config/api_keys.json
config/settings.local.json
memory/*.json
memory/*.db
models/
logs/
tmp/
.env
*.app/
crash-*.log
```

Also ignore common editor and packaging debris that does not hide source:

- `.idea/`
- `.vscode/` except if a future task explicitly tracks shared editor settings
- `*.egg-info/`
- `.pytest_cache/`
- `.mypy_cache/`
- `.ruff_cache/`

Create `.gitattributes` with text/LF defaults suitable for a cross-platform Python repo. Do not mark source files as binary.

Do not copy or create `config/api_keys.json`.
Do not add sample secrets.

## Tests

Wave 0 has no project test runner yet. Before commit, run:

```bash
git check-ignore -v config/api_keys.json memory/long_term.json .venv/models/dummy.bin logs/app.log tmp/x .env
```

Record the commands and results in the agent report. The integrator will re-run the same checks.

## Acceptance criteria

- `.gitignore` and `.gitattributes` exist.
- `git check-ignore` reports an ignore rule for `config/api_keys.json`, `memory/long_term.json`, `.venv/`, `models/`, `logs/`, `tmp/`, `.env`.
- No secret file is created or staged.
- Diff contains only owned paths.
- One logical commit.

## Deliverables

- `.gitignore`
- `.gitattributes`
- one commit
- report with SHA, file list, `git check-ignore` output, and integration notes

## Stop conditions

- request to copy real keys into the repository
- need to edit a forbidden path
- discovered secret in the worktree
