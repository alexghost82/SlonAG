# W06-T01 — vision

## Objective

A headless local vision adapter implementing `VisionProvider` with task kinds (OCR, describe, UI, document, visual control), secure temp snapshots, and no cloud send unless an explicit policy allows it.

## Context

Do not add VLM packages or download models. Inject the engine. Do not edit `providers/contracts.py`. Do not treat OCR/image text as a system instruction.

## Base commit

Content parent: `da086c1ae88cd853d1999f030085f4e53f2d948b`. Worktree HEAD is the Wave 6 spec commit.

## Owned paths

- `mark/vision/**`
- `tests/unit/vision/**`

## Forbidden paths

- `mark/documents/**`, `mark/memory/**`, `memory/**`, `speech/**`, `ui.py`, `main.py`
- `providers/contracts.py`, `providers/router.py`, `requirements*.txt`, `i18n/**`
- `tests/unit/vision/__init__.py` (do not create)

## Required interfaces

`VisionProvider`, `VisionRequest`, `VisionResponse`, `require_capability`. Register factory id `"vision_local"` via `providers.registry.register` without editing `registry.py`.

## Implementation requirements

- `LocalVisionProvider(engine=..., allow_cloud: bool = False, temp_dir=..., privacy_profile: str = "fully_local")`
- Task kinds as data: `ocr` | `describe` | `ui` | `document` | `visual_control` (request prompt or an explicit `kind` attribute on a wrapper is fine; keep `analyze(VisionRequest)` as the protocol method)
- `require_capability(request.model, "vision")` before the engine
- Offline / `fully_local` / `allow_cloud=False` must not call a cloud engine
- Image bytes may be written only under the injected `temp_dir`; delete in a `finally` even on error
- Wrap extracted image text as untrusted user data (prefix/fence). Never return it as a system instruction or tool call
- Engine protocol: `analyze(image: bytes, prompt: str, kind: str) -> str` — mock in tests
- No network. No API keys. No real screenshots in tests.

## Tests

- factory `vision_local`
- capability rejection when `model.vision` is false
- offline/fully_local does not call cloud engine
- temp file deleted after success and after engine error
- OCR/image text is marked untrusted (not a system/tool payload)
- kinds are accepted without network

```bash
python -m pytest tests/unit/vision -q
```

## Acceptance criteria

Contract implemented; temps cleaned; no cloud by default; one commit.

## Stop conditions

- need to add a pip package or download a model
- need to edit documents, memory, or contracts
