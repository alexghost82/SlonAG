# W03-T01 — gemini-adapter

## Objective

A Gemini `ChatProvider` that uses the official `google-genai` client behind mocks, implements streaming, and never reads `api_keys.json`.

## Context

Contracts live in `providers/contracts.py`. Call `require_capability` before `chat`/`stream`. Do not create or edit `providers/router.py`. Do not edit other adapter trees.

## Required interfaces

Use `ChatProvider`, `ChatRequest`, `ChatResponse`, `ChatEvent`, `ModelInfo`, `ProviderStatus`, `require_capability`, `ProviderAuthError`, `ProviderError`. Register a factory via `providers.registry.register` from `providers/gemini/__init__.py` or `provider.py` import side effect is allowed; do not edit `registry.py`.

## Implementation requirements

- `GeminiChatProvider(api_key: str | None = None, ...)`.
- Inject the API key through the constructor only. Do not open `config/api_keys.json`. Do not call `get_secret` unless you also accept an explicit key (prefer constructor only).
- `validate()` returns `ok=False` / `ProviderAuthError` path when the key is missing; do not hit the network in unit tests.
- `list_models()` returns at least one `ModelInfo` with `provider_id="gemini"`, capability flags set honestly (do not claim vision/audio on every model).
- `chat` / `stream` call `require_capability(request.model, request.role)` first.
- Streaming yields `ChatEvent(type="delta"|"done")`.
- Isolate `google-genai` usage inside this package. Unit tests must mock the client; no live Gemini calls, no real keys.
- Function-calling: accept optional tools on the request only if you can do it without changing `ChatRequest` (put extra kwargs on the provider method or ignore tools until contracts grow). Do not edit `contracts.py`. If tools need a contract change, file a change request and ship chat/stream without tools.
- No hidden model fallback list.

## Tests

`tests/unit/providers/gemini/` with mocked client:

- missing key → validate not ok, no network
- capability reject before client call
- chat returns `ChatResponse`
- stream yields delta then done
- `ModelInfo.provider_id == "gemini"`
- factory is registered as `"gemini"` after importing the package

Do not edit shared provider tests. No `tests/unit/providers/__init__.py`.

```bash
python -m pytest tests/unit/providers/gemini -q
```
