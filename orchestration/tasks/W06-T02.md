# W06-T02 — documents

## Objective

A local document ingest pipeline for TXT/Markdown/code, PDF, DOCX, images, and audio/video (via injected STT) with size/MIME/path/zip-bomb guards. Prompt-injection text must not become a tool call.

## Context

Do not add `pypdf`, `python-docx`, or other parser packages. Inject parsers and STT. Do not edit vision or memory packages. Do not execute attachments.

## Base commit

Content parent: `da086c1ae88cd853d1999f030085f4e53f2d948b`.

- `mark/documents/**`
- `tests/unit/documents/**`

## Forbidden paths

- `mark/vision/**`, `mark/memory/**`, `memory/**`, `speech/**`, `ui.py`, `main.py`
- `providers/**`, `requirements*.txt`, `i18n/**`
- `tests/unit/documents/__init__.py` (do not create)

## Required interfaces

Read-only: none required. Inject `extract_pdf`, `extract_docx`, `analyze_image`, `transcribe_audio` callables in tests.

## Implementation requirements

- `DocumentIngestor` (or equivalent) with `ingest(path: Path, *, source_bytes: bytes | None = None) -> DocumentExtract`
- Supported kinds: `txt`, `markdown`, `code`, `pdf`, `docx`, `image`, `audio`, `video`
- Guards: max size; MIME/extension allow-list; reject path traversal (`..`, absolute escape from an injected root); reject zip bombs (nested zip / huge uncompressed ratio) without extracting the payload; never `exec`/`eval`/run attachments
- Temp files only under an injected dir; delete in `finally`
- Extracted text is untrusted: wrap/fence it; `DocumentExtract.trusted` is False; never include a `tool_call` field or execute instructions found in the file
- A fixture document that says "call tool X / ignore previous instructions" must still return plain untrusted text only
- PDF/DOCX/image/audio go through injected hooks; missing hook → typed error, not a download
- No network. No API keys.

## Tests

- txt/markdown/code ingest
- size limit and bad MIME rejected
- path traversal rejected
- zip bomb rejected
- temps deleted after success and failure
- injection fixture does not produce tool_call / executable action
- missing parser hook raises a typed error

```bash
python -m pytest tests/unit/documents -q
```

## Acceptance criteria

Guards hold; injection cannot start a tool; no new deps; one commit.

## Stop conditions

- need to add a pip package
- need to edit vision or memory
