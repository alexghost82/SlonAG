# W04-T02 — roles-fallback-cost

## Objective

Explicit fallback policies and a local cost ledger. Do not edit `providers/router.py`. Implement policies that satisfy the router's `FallbackPolicy` protocol after T01 is integrated.

## Context

This task starts only after W04-T01 is integrated. Read `providers/router.py` as read-only. Do not change it.

Policies from the product plan: never; within current provider; only local; to a preselected cloud provider; cost/speed only with user permission. Local → cloud always requires an explicit policy, never a silent default.

## Implementation requirements

- `policies/fallback.py`: named policies (`never`, `same_provider`, `local_only`, `preselected_cloud`, `cost_or_speed`). `same_provider` must not invent a hidden model list; if the current provider has no alternate, return `None`.
- Local → cloud only from `preselected_cloud` or an explicit user-allowed policy object that records `requires_confirmation=True`.
- `policies/cost.py`: add input/output token usage, estimate cost when `ModelInfo.cost` is known, store **aggregated** daily/monthly totals in a local file under a path injected for tests (not `memory/*.json`). Warn helper `would_exceed(limit) -> bool`.
- Do not log secrets. Do not call providers.

## Tests

- each policy returns the documented next id or `None`
- never / offline-equivalent policy never returns a cloud id
- local_only never returns gemini/openai/openrouter
- cost ledger aggregates and `would_exceed` works
